## Модель данных

Проекта:
- module - обособленный и обладающий высокой сцепностью набор файлов конфигурации, пакетов и инструкций для достижения функционала
- group - именнованный набор модулей, который позволяет объединить воедино имеющий смысл набор функций
- host - имя хоста определяет набор или группу модулей

Модуля:
- name - имя модуля
- description - описание модуля
- pacman - список пакетов pacman для каждого модуля
- aur - список пакетов aur для каждого модуля
- after.sh - скрипт баш, который исполняется после устновки
- before.sh - скрипт баш, который исполняется до установки
- service - набор сервисов, которые должны быть включены
- userservice - набор пользовательских сервисов

Поддерживаемый команды:
- sync - команда автоматически производит все действия в системе
- diff - отобразить какие операции будут выполнены
- add/remove `--module` - команда устанавливает модули перечисленные с этой аннотацией

Поддерживаемые переменные окружения:
- ARCHSYNC_DIR - директория. default: `~/.config/archsync`
- ARCHSYNC_HOST - переопределить имя хоста. default: `/etc/hostname`
